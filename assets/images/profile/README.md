# Foto Profil

Unggah 4 foto berikut persis dengan nama file ini (format `.jpg`) ke folder ini:

- `profile-nav.jpg` — avatar kecil di navbar (rasio 1:1)
- `profile-hero.jpg` — foto besar di bagian Hero (rasio 3:4)
- `profile-about.jpg` — foto di bagian "Tentang Saya" (rasio 4:5)
- `profile-footer.jpg` — foto di bagian Kontak/Footer (rasio 1:1)

Cukup upload file dengan nama yang sama lewat GitHub (tombol **Add file → Upload files**),
menimpa placeholder yang tampil saat ini. Lihat `README.md` di root repo untuk detail lengkap.
