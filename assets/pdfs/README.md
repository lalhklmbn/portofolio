# Dokumen PDF

Unggah 3 berkas PDF berikut ke folder ini:

- `document-1.pdf` — ditampilkan sebagai "Curriculum Vitae"
- `document-2.pdf` — ditampilkan sebagai "Portofolio Cetak"
- `document-3.pdf` — ditampilkan sebagai "Sertifikat & Penghargaan"

Pratinjau halaman pertama akan otomatis muncul di halaman utama begitu
file diunggah dengan nama yang sama. Judul/deskripsi bisa diubah di
`index.html` pada bagian `id="dokumen"`.
